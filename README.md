# CS RETAKE

Aplikasi web simulasi dan evaluasi taktik retake 2D untuk Counter-Strike 2 (CS2).

## Fitur Utama

- **Simulasi Taktik 2D**: Penempatan waypoint jalur CT dan utilitas (smoke, flash, molotov) di atas peta taktis 2D.
- **Playback Simulasi**: Pemutaran ulang pergerakan agen CT, ekspansi utilitas, dan garis pandang musuh.
- **Evaluasi Taktik Otomatis**: Penilaian berbasis aturan untuk cakupan utilitas, sudut crossfire/entry, dan margin waktu retake.
- **Riwayat & Perbandingan**: Menyimpan dan membandingkan hasil simulasi taktik.
- **Autentikasi & Panel Admin**: Pengelolaan peran pengguna dan konten melalui panel admin.

## Struktur File

- `index.html` - Struktur antarmuka aplikasi.
- `styles.css` - Styling dan tata letak UI.
- `app.js` - Logika simulasi canvas 2D, evaluasi taktik, navigasi, dan manajemen data.

## Cara Menjalankan

Buka file `index.html` langsung di browser modern (Chrome, Edge, atau Firefox) tanpa perlu instalasi atau server tambahan.
